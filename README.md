# Project Cartridge

A controller-first Android front end that shows your game collection as physical media on a 3D shelf
and plays it with emulators built into the app. Each game sits in its retail case, browsed with a
gamepad, and starts without leaving the app.

Consoles: Game Boy, Game Boy Color, Game Boy Advance, NES, Super Nintendo, Genesis, Master System,
Game Gear, PlayStation, Dreamcast, GameCube and PlayStation 2 (with your own BIOS). Saturn is
implemented and needs its BIOS.

The emulators are Libretro cores and standalone engines compiled from pinned source:

| Console | Engine |
|---|---|
| Game Boy, Color, Advance | mGBA 0.10.5 |
| NES | FCEUmm |
| Super Nintendo | Snes9x 1.63 |
| Genesis, Master System, Game Gear | Genesis Plus GX |
| PlayStation | PCSX ReARMed |
| Saturn | Beetle Saturn |
| Dreamcast | Flycast 2.7 |
| GameCube | Dolphin |
| PlayStation 2 | ARMSX2 |

Rendering uses Filament (glTF), the UI is Kotlin and Jetpack Compose, and the emulator host is a
modified LibretroDroid 0.14.0 (see [libretrodroid/UPSTREAM.md](libretrodroid/UPSTREAM.md)). No ROMs,
BIOS files or commercial artwork are included.

The target device is the Retroid Pocket 5 (Android 13, arm64), but any arm64 Android device with
OpenGL ES 3.0 should run it.

## Prerequisites

- Windows, Linux or macOS with JDK 17 or 21.
- Android SDK: platform 35, build tools 35.0.0, NDK 27.2.12479018, CMake 3.22.1 and platform-tools.
  Android Studio can install these, or use `sdkmanager` below.
- The first build needs access to Google Maven, Maven Central and GitHub codeload. Once dependencies
  and source archives are cached, the app itself runs offline.
- Python 3.10+ is optional, for the lighting/sound generators and asset checks. Blender 4.2+ is only
  needed to re-convert the case models; an ordinary build uses the packaged GLBs.

## Build and test

Set `JAVA_HOME`, and set `ANDROID_HOME` or put `sdk.dir=C:/path/to/Android/Sdk` in `local.properties`
(ignored; use forward slashes on Windows).

```powershell
sdkmanager "platforms;android-35" "build-tools;35.0.0" "platform-tools" "ndk;27.2.12479018" "cmake;3.22.1"
.\gradlew.bat :app:assembleDebug :app:assembleDebugAndroidTest :app:testDebugUnitTest :app:lintDebug --console=plain
python tools/test_assets.py
```

On macOS/Linux use `./gradlew`. The wrapper pins Gradle 8.13 and verifies its SHA-256. CMake fetches
hash-pinned source for every core and builds arm64 libraries; there are no prebuilt core binaries. An
existing exact checkout can be supplied with `-PmgbaSource=`, `-PpcsxSource=`, `-PsnesSource=`,
`-PnesSource=`, `-PgenesisSource=` or `-PsaturnSource=` and an absolute path.

The first native build is slow: Beetle Saturn's generated 68000 interpreter alone takes around sixteen
minutes. Later builds reuse it.

Output: `app/build/outputs/apk/debug/app-debug.apk`.

Device tests run through `tools/Test-Device.ps1` (for example `-Suite Tour`, `-Suite Saves`,
`-Suite Browse`). They use original test programs generated by `tools/probe/`, never commercial games.

## Run

```powershell
adb devices -l
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n dev.cartridge/.MainActivity
```

## Using it

**First run.** An empty library is the welcome screen: press A and choose the folder that holds your
games (a parent of several console folders, one console's folder, or an SD card). Cartridge reports
what it found per console, adds it and opens the first shelf. The folder picker is Android's own and
the read grant is persisted; no broad storage permission is requested.

**Library.**

| Button | Does |
|---|---|
| D-pad / left stick | Browse the shelf |
| Right stick | Turn the focused case to look at it; it settles back when you let go |
| A | Play |
| X | Details |
| Y | Favourite |
| L1 / R1 | Previous / next shelf: each console with games, then All Games, Favorites, Recently Played |
| START | Menu: Add Games, Search, Artwork & Info, Refresh Library, Settings |
| B | Back. From the library it clears a search; with nothing to close it opens **Apps** |

Touch works too: screen edges browse, the case plays, the title opens details, and every *B Back*
hint is itself a back control.

**Apps** (B from the library) lists the Android apps installed on the device as a grid of their icons.
A opens one; B returns to the same shelf and game; Y searches. Cartridge only sees apps with a launcher
entry and asks for no extra permission to do it.

**Details** (X): play time, last played, description, then Play, Favorite, Game options (this game
only) and Manage game: find artwork online, use your own image, edit details, undo the last artwork
change, locate the file, hide from library. Hiding keeps the file, saves and artwork; restore it from
Settings › Library › Hidden games.

**In a game.**

| Buttons | Does |
|---|---|
| L3 + R3 (or Start + Select) | Pause menu: Resume, Quick Save, Quick Load, Save States, Game Options, Return to Library |
| L3 + Y / L3 + X | Quick save / quick load |
| L3 + B | Freeze the game without opening a menu |
| L3 + A | Fast-forward, on consoles that support it |

All combos can be re-recorded in Settings › Controls. *Save States* lists the quick save, the one it
last replaced and every save you make, each with a thumbnail. Android's Back also pauses.

**Settings** (START › Settings): Library, Appearance, Gameplay, Controls, Shaders, System, Advanced.
Gameplay options are grouped by console, and a game can override them from its details or pause menu.

**Shaders.** Settings › Shaders › Update shaders downloads RetroArch's GLSL shader library from GitHub.
Choose a preset for every console, per console or per game; each preset is compiled on the device
before it is saved, and one that fails falls back to the normal picture.

## Importing

| Console | Files |
|---|---|
| Game Boy, Color, Advance | `.gb` `.gbc` `.gba` |
| Super Nintendo | `.sfc` `.smc` `.swc` `.fig` |
| NES | `.nes` `.unf` `.unif` |
| Genesis | `.md` `.gen` `.smd`, and `.bin` inside a folder named for Genesis or Mega Drive |
| Master System, Game Gear | `.sms`, `.gg` |
| PlayStation | CUE/BIN folders; CHD, PBP, ISO and PS-X EXE files |
| Saturn | CUE/BIN folders; CHD inside a folder named for Saturn |
| Dreamcast | GDI folders; `.cdi`; GD-ROM `.chd`; CUE/BIN and CHD inside a folder named for Dreamcast |
| PlayStation 2 | DVD `.iso` and `.chd`; `.iso`, CUE/BIN, `.cso`, `.isz` inside a folder named `ps2` or PlayStation 2 |
| GameCube | `.iso` `.gcm` `.rvz` `.gcz`; `.ciso` inside a folder named for GameCube |

Every file is identified by its first bytes before it is copied, so stray files beside your games are
skipped. Disc images are matched to their console by their own headers where possible, otherwise by
the folder they are in. Discs of the same game are grouped into one entry, found by an `.m3u` in the
folder or by names that differ only in `(Disc N)`; you can group or separate discs by hand from
Details, and every change can be undone. Change Disc is offered in the pause menu where the engine
supports it.

Each game gets a SHA-256-addressed working copy in app-private storage; your original files are never
changed. Duplicates are recognised by content, never by title. Remembered folders are refreshed when
Cartridge opens, and Settings › Advanced › Check every game file rehashes everything.

**BIOS files** are yours to supply and are added under Settings › Gameplay › the console. Cartridge
recognises a BIOS by its contents, keeps it private, and never downloads or backs it up. PlayStation
runs without one (HLE, with lower compatibility); Saturn and PlayStation 2 need one.

## Saves

Battery saves are restored before the first emulated frame and written every 15 seconds when they
change, on pause and when a game ends. Putting the device to sleep or leaving the app writes a
checkpoint; on the next launch the menu offers **Continue <game>**. Engines that cannot be captured
stay loaded and paused instead. Settings › Gameplay › Start from save state (off by default) starts
games from their last save state; if the state cannot be loaded the game starts from the beginning
instead. Settings › Library › Backup writes a portable archive of the library, artwork and saves
(never ROMs, BIOS files or logins).

## Artwork

Artwork and details come from [ScreenScraper](https://www.screenscraper.fr) (with your own account
and developer ID, entered under Settings › Library › Artwork; nothing is built in) or the
[RetroBase Collection](https://retrobase-collection.com). Added games take the best match
automatically and fill only what is missing; START › Artwork & Info runs the same for a console, a
selection or the whole library, and a single game can be searched from Details. Choices you made by
hand are only replaced when you ask, and each run has one Undo. Lookups send ROM checksums, size and
titles, never ROM contents. Accepted images are cached for offline use. You can also use your own
PNG, JPEG or WebP from Manage game.
